**Milestone:** Chapter 12 · EeePC 1005P first physical USB boot

The EeePC reached its GRUB menu from the rescue USB, then showed a black screen with the initial boot configuration. A temporary GRUB edit kept the original root PARTUUID and rootwait, selected `console=tty0`, removed the serial-console argument, and added `nomodeset loglevel=7`. The machine then reached a local console login and ran the inventory commands. This establishes a working boot configuration. The session did not isolate which display or console argument resolved the symptom.

### Hardware-specific kernel and v2 media build

PCI inventory identified Ethernet `1969:1062` (AR8132), Wi-Fi `168c:002b` (AR9285), and Intel HDA controller `8086:27d8`. The rebuilt EeePC profile selects atl1c, ath9k, Intel HDA and candidate Realtek codec support. The actual codec and runtime device operation are pending.

Baihu built Linux 7.1.8 and its modules from checkout `e966fdc`, then built and verified both images in `/home/john/eeepc-media-v2`. The local-console GRUB option is the new default for EeePC images.
